## 5. 결론
- PASS/FAIL/BLOCKED 사유: TC-13에 명시된 사례 "후딘(교환)"이 실제 화면에서 `연결의끈 사용`으로 나와 통신교환 조건이 표시되지 않는다. 같은 원인으로 12종, 밀로틱까지 13종이 통신교환 방법을 잃는다. FR-28 인수 조건("통신교환 ... 조건이 진화 단계 사이에 표시된다")을 지정 사례에서 깨므로 **FAIL**. 이브이(돌)·시간대·친밀도·특수 조건은 정상이다.
- 남은 위험/미검증 항목: PokéAPI 진화 데이터가 바뀌면 표시도 바뀐다(이번에 리뷰 시점과 결과가 다름). 모바일 폭·다크 모드·스크린리더 실사용 미확인. 장소 한국어명은 dusty-bowl 하나만 번역표에 있음(OQ-18).
- 수정 요청: (1) "최신 게임만" 규칙을 바꾸거나 보완(예: 본편 최신판에 기록이 없는 교환 방법 유지, LA 전용 도구 방법은 교환과 함께 표시) — 규칙 자체는 팀 결정 필요. (2) 밀로틱 예외 처리. (3) 판 이름 오타·누락 수정. (4) 실제 API처럼 여러 판이 섞인 체인으로 후딘·밀로틱 회귀 테스트 추가.
