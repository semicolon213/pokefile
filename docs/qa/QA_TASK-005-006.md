## 5. 결론
- **FAIL 사유:** 상세 기능 자체는 대상 인수 조건(FR-10~16·18, TC-04·05, NFR-07)을 모두 충족하고 lint·typecheck·test·build도 통과했다. 그러나 TEST_PLAN §4 "해당 자동 테스트 명령 성공" 기준에서 `npm run test:e2e`가 3건 실패하며, 이 실패는 이 PR의 동작 변경 때문에 생긴다(D-1). **제품 코드 수정은 필요 없고**, 다른 담당자 소유 테스트의 단언 3개만 갱신하면 된다.
- **남은 위험/미검증 항목:**
  - QA 독립성 미충족(구현과 같은 Claude) — 사람 확인 또는 Codex 재검증 필요.
  - PR #2 CI 결과 미확인(`gh` 없음). E2E는 CI 필수 단계가 아니므로 CI가 통과해도 D-1은 남는다.
  - 반응형(NFR-01)·키보드(NFR-08) 수동 검수와 GitHub Pages 배포 확인 미실행.
  - OQ-17(도감 설명 버전), OQ-18(장소 한국어명)은 **OPEN 상태에서 제안값/임시안으로 구현**했다. 팀 결정이 다르면 수정해야 한다. `docs/TASKS.md`에 이 사실이 표기되어 있다.
  - 실전 세팅의 폼 연동(`formKey` 전달)은 TASK-007과의 계약이 미합의다(`PokemonDetailPage.tsx:151` TODO).
- **수정 요청:** D-1 (필수, 병합 전). D-2·D-3은 병합 후 후속 이슈로 처리 가능.
- **사람 승인자:** 기능 오너 임지섭(최종 병합), 교차 확인 성윤우(ADR-014), D-1 테스트 파일은 김형균.
